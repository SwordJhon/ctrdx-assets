# Cut the Rope DX assets

This repository hosts the asset packs required to build and run **Cut the Rope DX**.

The assets are provided through the [**Releases**](https://github.com/yell0wsuit/ctrdx-assets/releases) section.

## Usage

1. Go to the [**Releases**](https://github.com/yell0wsuit/ctrdx-assets/releases) section.
2. Download the latest asset pack.
3. Extract the asset pack into the `content` folder of your local **Cut the Rope DX** source tree.
4. Build or run the game normally.
